# Top E-Learning Authoring Software Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Interactive Course Authoring, SCORM/xAPI Packaging & Responsive Content Design*  
**Last updated: October 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **E-Learning Authoring Software**. These tools enable instructional designers and L&D teams to create interactive, multimedia-rich courses, assessments, and simulations, then export them as SCORM, xAPI, or cmi5 packages for delivery through any learning management system.

**Examples** include Adobe Captivate, Articulate 360, Articulate Storyline, iSpring Suite, Elucidat, dominKnow | ONE, Lectora Online, Easygenerator, Coassemble, and Camtasia (the category leaders).

**Open-source emphasis**: This section is heavily expanded with active projects for self-hosted authoring environments, interactive content frameworks, and file-based course generation — ideal for educational institutions, training providers, and developers building sovereign content pipelines without per-seat licensing lock-in.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Adobe Captivate](https://www.adobe.com/products/captivate.html)**  
  Desktop authoring tool for creating responsive e-learning with simulations, VR projects, and quiz generation; strong for software training and scenario-based content.

- **[Articulate 360](https://articulate.com/360)**  
  Suite including Storyline 360 (interactive course authoring), Rise 360 (responsive block-based courses), and Review 360 for collaborative feedback.

- **[Articulate Storyline](https://articulate.com/storyline)**  
  Industry-standard desktop authoring tool with triggers, variables, and layers for building complex branching scenarios and highly interactive courses.

- **[iSpring Suite](https://www.ispringsolutions.com/ispring-suite)**  
  PowerPoint-integrated authoring toolkit with quizzes, simulations, screen recording, and direct publishing to SCORM/xAPI/cmi5 LMSs.

- **[Elucidat](https://www.elucidat.com/)**  
  Cloud-based collaborative authoring platform for rapid production of responsive, multi-device e-learning with built-in analytics and translation workflows.

- **[dominKnow | ONE](https://www.dominknow.com/)**  
  Enterprise authoring platform supporting both page-based and slide-based workflows, with content reuse, responsive output, and team collaboration.

- **[Lectora Online](https://www.lectora.com/)**  
  Cloud-based authoring tool (formerly Trivantis) with responsive design, branching scenarios, and SCORM/xAPI compliance for corporate training.

- **[Easygenerator](https://www.easygenerator.com/)**  
  Cloud authoring tool designed for subject matter experts, with a simple interface, built-in templates, and direct LMS publishing.

- **[Coassemble](https://www.coassemble.com/)**  
  Collaborative authoring platform for creating microlearning and engaging courses with templates, quizzes, and built-in LMS functionality.

- **[Camtasia](https://www.techsmith.com/camtasia/)**  
  Screen recording and video-based authoring tool for creating software tutorials, training videos, and interactive video lessons with quizzes.

## Open-Source GitHub Projects

- **[eXeLearning](https://github.com/exelearning/exelearning)**  
  AGPL-licensed authoring tool maintained by the Spanish Ministry of Education; features iDevices for interactive elements, Moodle integration, real-time collaborative editing via Yjs, Docker deployment, and offline installers for Linux/Windows/macOS .

- **[Adapt Authoring Tool](https://github.com/adapt-security/adapt-authoring)**  
  Web-based UI for the Adapt framework; creates fully responsive, multi-device HTML5 courses with SCORM compliance, built on Node.js/Express/MongoDB/React, and published under GPL-3.0 .

- **[Adapt Framework](https://github.com/adaptlearning/adapt_framework)**  
  Open-source toolkit for building responsive, accessible e-learning courses; features 23 bundled plug-ins, WAI AA accessibility, xAPI support, and delivery via SCORM LMS or web server; GPL-3.0 licensed .

- **[H5P](https://github.com/h5p/h5p-core)**  
  Open-source HTML5 interactive content framework with 50+ content types (interactive videos, quizzes, presentations, branching scenarios); LMS-agnostic via LTI, embeddable in Moodle/WordPress, and exportable with SCORM/xAPI tracking .

- **[CourseCode](https://github.com/coursecode/coursecode)**  
  Local-first, file-based course authoring framework with AI/MCP integration; creates real project files, exports SCORM 1.2/2004, cmi5, and LTI, includes live preview, TTS narration, and WCAG 2.1 AA accessibility .

- **[LiaScript](https://github.com/LiaScript/LiaScript)**  
  Open-source markup-based authoring tool for creating interactive online courses using a simple text format; supports animations, quizzes, code execution, and collaborative OER development via GitHub .

- **[Opale (Scenari)](https://scenari.software/)**  
  Free and open-source authoring software from the Scenari project for creating pedagogical content; outputs SCORM 1.2/2004, printable PDF, and web formats with accessibility-focused skins including dyslexia-friendly options .

- **[Open eLearning](https://github.com/openelearning/openelearning)**  
  Free, open-source e-learning authoring editor for Linux, macOS, and Windows; designed to counter the privatization of knowledge creation with freely shareable course content .

### Additional Strong Open-Source Options

- **Lumi** — Desktop application for creating, editing, and exporting H5P content offline without requiring an LMS or internet connection .
- **SCORM packaging tools** — Community scripts and libraries (e.g., `scorm-packager` npm packages) for wrapping HTML5 content into SCORM 1.2/2004 packages.
- **FFmpeg** — Foundation for video processing and post-production in course authoring pipelines.
- **Audacity** — Open-source audio editor for narration and voiceover production in e-learning modules.
- **Inkscape / GIMP** — Vector and raster graphics editors for creating visual assets and interactive content components.

**Frameworks for building custom systems**: Combine **eXeLearning** or **CourseCode** for structured course authoring, **H5P** for reusable interactive elements, **Adapt Framework** for responsive multi-device delivery, and **Lumi** for offline H5P editing in a fully self-hosted e-learning content creation pipeline.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- E-learning content must comply with accessibility standards (WCAG, Section 508) and applicable data privacy regulations.
- Self-hosted open-source solutions require proper security hardening, backup planning, and LMS compatibility testing.
